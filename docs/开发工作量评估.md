# 省儿童 PICU 专病库 — 开发工作量评估

> 技术栈：Vue 3 + TypeScript + Element Plus / Spring Boot + MySQL + Redis，RESTful API

---

## 总表

| 编号 | 模块 | 功能点 | 人天 |
|------|------|--------|------|
| 1 | **基础架构与共享** | 前后端脚手架搭建、布局与壳组件、共享 UI 组件库、类型系统与数据模型、Mock 迁移真实 API | 3 |
| 2 | **数据来源与治理** | 治理概览卡片与统计、原始多表浏览、设备文件视图（影像+提取字段）、来源标签体系 | 11 |
| 3 | **项目/队列管理** | 队列 CRUD、入排规则引擎（条件树可视化+持久化）、定时扫描任务、候选患者池与状态操作 | 14 |
| 4 | **队列全景看板** | KPI 指标面板、病因分布图、离线设备上传管理、入组病例多维表格与筛选 | 10 |
| 5 | **CRF 填审工作站** | 模板引擎配置、模块侧栏与字段过滤、字段卡片控件渲染、状态流转与提交、来源证据抽屉、床边观测面板 | 15 |
| 6 | **字段映射** | 多维度筛选栏、映射表格与元数据展示、映射关系维护 | 5 |
| 7 | **查询分析** | 查询模板 CRUD、结果表格与分页、结局分布图、KM 生存曲线、危重度评分趋势 | 12 |
| 8 | **导出中心** | 导出预设界面、后端导出引擎（CSV/SPSS/文件打包）、任务管理与状态轮询、历史记录 | 8 |
| 9 | **首页与入口** | 首页布局与工作流、功能模块网格、队列概览统计、登录/权限框架预留 | 4 |
| 10 | **用户认证与权限** | 登录登出、Token 鉴权与路由守卫、RBAC 角色模型、页面级权限控制 | 6 |
| 11 | **系统运维与部署** | Docker 容器化、数据库初始化与迁移、CI/CD、Nginx 部署、日志与监控预留 | 2 |
| | **合计** | | **90** |

> **总人天 90 天**（约 4.5 人月，5 人全栈团队约 4 周）。
>
> 不含需求调研、UI 设计、用户测试验收。实际工期浮动 ±20%。
